
# 📦 PAPAS - Sistema de Gestión de Almacén

**PAPAS** es una aplicación desarrollada con **Spring Boot**, **MySQL** y **Docker** orientada a la gestión eficiente de inventarios, control de stock, roles de usuario y auditoría del sistema.

---

## 🚀 Tecnologías Utilizadas

* **Backend:** Java, Spring Boot, Spring Data JPA, Hibernate, Maven
* **Base de Datos:** MySQL 8.0
* **Contenedorización:** Docker, Docker Compose
* **IDE & Herramientas:** Apache NetBeans, Git, GitHub, Render

---

## 🛠️ Características Principales

* 🔐 **Gestión de Roles y Seguridad:** Control de acceso diferenciado (`admin` / `user`).
* 📦 **Control de Almacén:** Administración y operaciones sobre productos e inventario.
* 📄 **Paginación y Filtros:** Búsquedas optimizadas y navegación en los listados.
* 🕒 **Auditoría:** Registro de fechas y trazabilidad en las operaciones.
* 🐳 **Infraestructura Dockerizada:** Despliegue listo para entornos locales y producción mediante contenedores.
